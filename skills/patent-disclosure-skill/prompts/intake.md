# 边界与输入录入（Step 1）

## 用途

在开始专利挖掘与交底书撰写前，用**少量问题**收敛案件边界。信息不全时可跳过，由 Agent 后续推断并**注明假设**。

## 可选开场

```
为便于挖掘专利点与组织交底书，先确认几项边界；可跳过，将按已有材料推断。
```

## 问题序列

### Q0：目标立案机构（决定走哪个模板分支）

```
本交底书将提交给哪个机构/场景？这会决定章节结构与要点的差异。

A. 中移/集团/运营商立案（如中国移动集团）→ 走「13 章制」模板（含术语表、商业价值、侵权证据、术语解释、项目信息、产品信息、技术交底书撰写点评等章节，参考集团 5 篇范文 XX2209082/CMII2204017/CMII2203007/HZYF2112012/MGSX2205129）
B. 通用/企业内审/快速申报/学术参考 → 走现有「6 章制」模板（默认技术背景→技术问题→技术方案→优点→关键点和欲保护点→其它）
```

> 该问题决定 `disclosure_builder.md` §7.1 的分支；不再询问则按 B（6 章制，保留历史行为）。

### Q1：技术主题或产品模块

```
请用一句话描述本方案所属技术主题或产品模块，例如「多模态检索排序」「工业质检缺陷分级」。
```

### Q2：专利类型倾向

```
是否已有倾向的权利要求类型？方法 / 系统 / 装置 / 暂不确定
```

### Q3：文头联系人

```
交底书文头的技术联系人是否需要占位？需要则提供姓名/电话/邮箱；不需要则全部写「待填写」。
```

## 汇总

将已确认项用 3–6 行 bullet 复述给用户，再进入 `project_scan.md` 对应的扫描阶段。
